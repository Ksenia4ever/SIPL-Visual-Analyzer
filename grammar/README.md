# SIPL Grammar

This directory contains the formal grammar of the SIPL language.

## Planned implementation

The language grammar will be implemented using Lark.

The grammar will support the basic SIPL constructs:

- Assignment
- Sequential composition
- Conditional statements
- While loops
- Begin/end blocks
- Skip statements
- Arithmetic expressions
- Boolean conditions

The grammar must correspond to the BNF specified in the
Theory of Programming course materials.

## Validation

CORE-01 requires:

- A machine-readable grammar
- Lexical specification
- At least 10 positive tests
- At least 10 negative tests
- Examples of valid and invalid SIPL programs

Implementation is planned for Stage 2.
